# AI 能力罗盘 · 技术栈说明

> 面向评委与技术评审的技术选型文档。架构与流程详见《技术架构文档》，开源组件清单详见《开源使用声明》。

## 总体形态

前后端分离单仓（monorepo），生产形态为**单容器部署**：FastAPI 进程同时提供 REST API 与前端静态资源，一个端口即可服务全部功能。

```
ai-compass/
├── web/    # 前端 SPA（React 19 + TypeScript + Vite + Tailwind + shadcn/ui + Recharts）
├── api/    # 后端（Python 3.13 + FastAPI + SQLAlchemy 2.0 + SQLite WAL）
├── seeds/  # 题库（1000 题 JSON，版本化）与分级建议库（30 格）
├── scripts/# 部署脚本（setup.sh / start.sh）与校准、冒烟脚本
└── docs/   # 设计文档、提交材料、校准报告
```

**模块划分**（`api/app/`）：`engine/`（自适应引擎+判分，纯函数、copy-on-write）、`judge/`（LLM 判题管线：校验→重试→降级→双跑一致性→复核入队；统计指标）、`llm/`（provider 抽象 + mock，模型角色分工：判题 v4-pro / 对话 flash）、`report/`（报告生成：雷达/等级/分级建议库融合）、`api/`（六组路由）。

## 大模型

| 角色 | 模型 | 场景 |
| --- | --- | --- |
| 判题 | `deepseek-v4-pro`（temperature=0，JSON mode） | 开放题/对话题/实操双通道评分——**双跑一致性 + 分差三跑中位**，校准 Kappa 0.983 |
| 对话 | `deepseek-flash`（流式） | 考官三档追问、实操协作窗、报告建议（低延迟低成本） |

接入层 provider 化（OpenAI 兼容），更换模型/厂商仅需环境变量。评分准确性验证：50 样本双盲校准，Pearson 0.985 / 加权 Kappa 0.983（见《评分准确性验证报告》）。

## 核心算法

- **自适应引擎**（Elo 期望式）：每维独立 θ∈[1,5]，期望掌握度 `1/(1+e^(-(θ-d)))`，步长随答题数衰减，连错/n≥6/收敛停止，连对需触达题池难度上限——强学员真实爬升至 L5。
- **判题校验链**：pydantic 校验失败重试 ≤2 → 关键词覆盖度降级 → 双跑分差 >1 三跑取中位 → 仍分歧入人工复核队列。
- **异步并行判题**：finish 即时 202 返回，线程池并行（实操过程/产物内层再并发），前端轮询 `judging_step/total` 进度。

## 测试与质量

- 后端 268 项测试（引擎锚点/判题链路/权限矩阵/SSE 边界/并发回滚），全部零真实 LLM 调用（结构性禁用）。
- 前端 27 项测试 + `tsc` 构建门禁。
- 外部 IO 测试一律 MockTransport 保真签名（防"mock 宽容签名骗过测试"）。
- 真实验证：浏览器端到端走查 + 真实 DeepSeek 全链路联调（见 docs/）。
