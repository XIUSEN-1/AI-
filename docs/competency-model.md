# AI 能力罗盘 · 能力等级锚定模型

本模型定义六个维度 × 五个等级（L1~L5）的行为锚定，用于解读测评报告中的等级评定，并指导题库编制与教学建议。等级名称与引擎一致：**L1 初识 / L2 会用 / L3 熟练 / L4 精通 / L5 专家**。

## 一、六维 × L1~L5 行为锚定表

每格描述该维度上处于该等级的学习者**可观察到的典型行为**，内容从题库各维度考点归纳（D1~D6 每维 10 个基础考点 + 5 个进阶考察要点）。

### D1 AI 基础认知

| 等级 | 行为锚定 |
| --- | --- |
| L1 初识 | 能说出大模型"能对话、能写文章"等表面功能，但分不清 token、上下文窗口、知识截止等概念，把幻觉当作"软件故障"。 |
| L2 会用 | 能准确区分预训练与微调、上下文窗口与知识截止日期等概念，知道幻觉源于模型按概率生成而非硬件或网络问题。 |
| L3 熟练 | 能解释幻觉机理与判别式/生成式模型的差异，了解多模态能力范围，面对具体任务能判断其是否超出模型当前能力边界。 |
| L4 精通 | 能从训练与推理两端系统解释模型行为，比较预训练/微调/提示工程三种适配方式的成本与适用条件，能为长文档等边界场景设计处理策略（分块、检索、压缩）。 |
| L5 专家 | 能跟踪能力边界随版本演进的移动并形成判断方法论（错误代价、可验证性、任务结构化程度），可诊断真实场景中"知识过时/幻觉/上下文缺失"类问题并给出修复与验证方案。 |

### D2 提示词工程

| 等级 | 行为锚定 |
| --- | --- |
| L1 初识 | 写"帮我写个东西"式模糊指令，首轮输出不满意时只会原样重发或直接放弃。 |
| L2 会用 | 能写出含目标、对象、格式、约束的完整指令，会使用角色设定与上下文给料，能用具体反馈（而非"再好点"）驱动修改。 |
| L3 熟练 | 能按任务设计少样本示例与输出格式控制，理解思维链的适用场景与反面指令陷阱，通常两三轮迭代内收敛到可用产出。 |
| L4 精通 | 能诊断失败提示词的要素缺失并做结构化改写（角色/任务/材料/格式/约束），会为分类等任务设计示例集并用测试集验证有效性，能让模型稳定产出合法 JSON 等格式化输出。 |
| L5 专家 | 形成个人提示方法论：按任务类型选择策略（思维链/少样本/分步拆解），对指令版本做 A/B 对比，沉淀可复用模板，并知道何时止损、停止迭代。 |

### D3 AI 工具使用

| 等级 | 行为锚定 |
| --- | --- |
| L1 初识 | 只在网页对话框里做过简单问答，不清楚 AI 工具还有哪些类型与用法。 |
| L2 会用 | 能按场景选对工具大类（语音转写、文生图、办公插件、联网检索），了解联网与离线模式的差别，会设置隐私授权选项。 |
| L3 熟练 | 能完成多工具串联任务（转写→提炼→成图），了解 API 计费方式与版本差异的影响，对关键数字与产出做抽查核对。 |
| L4 精通 | 能为多环节任务设计工具组合工作流并设置人工介入点与质量关卡，能管理 API 成本（模型分级、缓存复用、用量监控与配额）。 |
| L5 专家 | 构建并维护个人/团队工具矩阵与可复用 SOP，量化评估工作流的效率与质量得失，持续跟踪新工具并迭代选型。 |

### D4 AI 结果评估与优化

| 等级 | 行为锚定 |
| --- | --- |
| L1 初识 | 凭感觉全盘接受或全盘否定 AI 输出，把"语气自信"当作"内容正确"。 |
| L2 会用 | 知道事实性信息使用前须核实、用原始出处验证数字，能识别时效性问题的风险，能撰写针对具体问题的改进指令。 |
| L3 熟练 | 能识别幻觉、偏见、逻辑漏洞（如必要条件当充分条件）三类典型问题，会用相互独立的来源做交叉验证，了解 AI 检测工具存在误判。 |
| L4 精通 | 能设计并执行分层核查清单（事实/时效/来源/逻辑/偏见/格式），对重要产出形成"可采用/修改后采用/退回"的判定，并驱动多轮迭代优化。 |
| L5 专家 | 建立团队级评估框架与量化判定规则，理解检测工具的技术原理与误判来源，能设计兼顾公平与效率的评估机制（过程证据、抽查策略、偏差控制）。 |

### D5 人机协同解决问题

| 等级 | 行为锚定 |
| --- | --- |
| L1 初识 | 把任务整块丢给 AI"一键完成"，或坚持完全不用 AI；出问题后不知道从哪个环节改起。 |
| L2 会用 | 会先拆解任务再分工，明确决策与担责环节必须由人完成，AI 产出经人工整合核对后交付，并保留协作留痕。 |
| L3 熟练 | 能设计含迭代检查点与失败回退预案的协同流程，串联多工具执行，"越改越乱"时能回退基线、小步验证、及时止损。 |
| L4 精通 | 能用风险高低/可逆性/标准明确度框架决策人机边界，端到端评估协作效率（把学习、调试、核验等隐性成本计入），持续优化分工。 |
| L5 专家 | 把协作经验固化为团队规范与模板，在复杂项目中编排人机流程、界定质量责任，能复盘失败案例并带教他人改进协作方式。 |

### D6 AI 伦理与合规

| 等级 | 行为锚定 |
| --- | --- |
| L1 初识 | 知道"不该用 AI 作弊"，但说不清隐私、版权、标注等具体合规要求。 |
| L2 会用 | 提交个人信息前先脱敏、公开发布 AI 生成内容时如实标注、按课程要求披露 AI 参与，收到疑似深伪的求助信息会走独立渠道核实。 |
| L3 熟练 | 能识别偏见输出并主动纠偏，掌握版权与责任归属的基本规则（使用者担责、AI 非法律主体），能在发布前执行脱敏、标注与查重检查。 |
| L4 精通 | 能设计覆盖隐私/版权/标注/学术诚信/数据安全的合规检查清单并落地执行，能预判场景风险与红线，处置深伪等事件的流程完整（不扩散、留证据、平台举报、报警）。 |
| L5 专家 | 能参与制定组织级 AI 使用规范（制度/技术/教育三层），理解法规要求与"防风险不扼杀创新"的治理平衡，在团队内示范并推动负责任使用。 |

## 二、等级评定规则（θ → 等级映射）

### 1. 能力估计 θ 的产生

测评引擎（`app/engine/adaptive.py`，Elo 期望式更新）为每个维度维护能力估计 **θ**：

- 取值范围 **1.0 ~ 5.0**，初始值 3.0；题目难度与 θ 同为 1~5 尺度。
- 每次作答后更新：`delta = k · (result − expected(θ, difficulty))`，其中期望掌握度 `expected = 1 / (1 + e^(−(θ−难度)))`，步长 k 随该维度答题数衰减。客观题 result 为 0/1；进阶开放题/实操题依据 rubric 的 0~4 档锚定评分，以 `score/4` 折算为 result。
- 答对 θ 上调、答错下调；连续答对/答错达到阈值、答题数达上限或更新量收敛时该维度停止出题。

### 2. θ → 等级映射表

与引擎 `dimension_level` 完全一致（左闭右开）：

| θ 区间 | 等级 | 名称 |
| --- | --- | --- |
| [1.0, 1.8) | L1 | 初识 |
| [1.8, 2.6) | L2 | 会用 |
| [2.6, 3.4) | L3 | 熟练 |
| [3.4, 4.2) | L4 | 精通 |
| [4.2, 5.0] | L5 | 专家 |

**总等级**：六个维度 θ 的算术平均值，再过同一映射函数得出。

### 3. 与题库的对应关系

- 基础题（难度 1~3）对应 L1~L3 的知识性要求：每题考察一个明确考点，用于快速定位 θ 区间。
- 进阶题（难度 4~5，开放题/实操题）对应 L4~L5 的应用性要求：rubric 的 0~4 档锚定与 L1~L5 行为锚定同构——0 档约对应"未入门"，4 档约对应"专家级表现"，评分结果折算进 θ 更新，实现基础认知与高阶能力的统一量尺。

- v1（2026-09）：随题库 v1（90 题）发布；行为锚定由 v1 题库考点归纳生成。
