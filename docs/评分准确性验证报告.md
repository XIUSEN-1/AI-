# 评分准确性验证报告（M2d 校准实验）

> 实验日期：2026-09-13 · 样本 N=50 · 开放题 48 道（覆盖 D1~D6 全部 6 个维度）· 脚本真实调用 LLM 完整跑通一次
> 原始数据：`docs/calibration/samples.csv`（50 行逐样本 judge 分 / 标注分 / 理由）· 复现脚本：`api/scripts/calibration.py`

## 1. 目的与背景

AI 能力罗盘的主观题判分采用 LLM 管线（`judge_answer`，v4-pro 双跑 + 降级），其输出直接决定学员能力雷达与等级，是评分方案中"准确性"权重的核心证明材料。本实验依据总体设计 §9（校准实验）执行：构造已知质量差异的开放题作答样本，让线上判分管线与独立标注代理分别打分，用相关系数与一致性指标量化判分管线的评分准确性。

## 2. 方法学（如实声明）

**重要声明：本实验的"标注"由 AI 独立评审代理完成，不是人类标注。** 标注代理与判分管线使用同一供应商的同一底座模型（deepseek-v4-pro），但 prompt 相互独立、互不可见。它与人类评分的一致程度可能低于本报告数字，局限详见 §6。

### 2.1 样本构造（generator：deepseek-flash）

- 从种子题库抽取全部 48 道主观 open 题（D1~D6 各 8 道），循环取样至 50 份（2 道重复，维度覆盖 9/9/8/8/8/8）。
- 每份作答按四档质量由 flash 生成：**优**（逐条命中 rubric 要点并具体展开，13 份）、**中**（约命中一半要点，13 份）、**差**（泛泛套话不触要点，12 份）、**跑题**（答非所问，12 份）——各约 25%。
- 档位与题目的配对用固定随机种子（seed=42）洗牌，避免档位与特定题目绑定；实验可精确复现。

### 2.2 判分管线（与线上一致）

被测方是生产代码路径本身：`app/judge/pipeline.py::judge_answer`——同一 prompt 双跑并发（temperature=0），|Δ|≤1 取均值四舍五入，|Δ|>1 追加第三跑取中位，解析失败降级关键词覆盖度。本实验中 0 份降级、0 份触发复核。

### 2.3 独立标注代理（"人工基准"的代理）

- 模型同为 deepseek-v4-pro（`model_role="judge"`），但使用**独立编写的评分官 prompt**：只看题面 + 评分要点 + 作答，按 0~4 档锚点独立给分并输出一句话理由。
- 标注代理**看不到**判分管线的任何输出（分数/hits/rationale），也**不知道**质量档位；判分管线同样看不到标注结果——双向盲评。
- 标注规程与总体设计 §9 一致："只看题面+rubric+作答"。

### 2.4 指标

Pearson 相关系数、Spearman 等级相关、二次加权 Kappa（`app/judge/stats.py` 纯函数实现，构造数据单测 17 项验证数学正确性）、精确一致率、相邻一致率（|Δ|≤1）、5×5 混淆矩阵。

## 3. 核心结果

| 指标 | 数值 | 释义 |
| --- | --- | --- |
| **Pearson r** | **0.9846** | 判分与标注的线性一致性 |
| **Spearman ρ** | **0.9840** | 排序一致性 |
| **二次加权 Kappa** | **0.9830** | 剔除随机一致后的加权一致性（>0.81 为"几乎完全一致"区间） |
| 精确一致率 | 90.0%（45/50） | 两方给分完全相同 |
| 相邻一致率（\|Δ\|≤1） | 100% | 无一例跨两档以上的分歧 |
| 判分双跑完全同分 | 46/50 | 其余 4 份 |Δ|=1，双跑一致性好 |
| 降级 / 需复核 | 0 / 0 | 判分管线全程未触发降级或人工复核 |

**结论：在 50 份四档质量样本上，线上判分管线与独立标注代理达到几乎完全一致（Kappa 0.983、Pearson 0.985），全部分歧都在相邻档内。**

## 6. 局限（如实）

1. **标注非人类**：标注代理是同供应商（DeepSeek）同一底座模型的独立 prompt 实例，与判分管线可能共享系统性偏差（相关误差），真实人机一致率可能低于本报告数值。本实验证明的是"判分管线稳定、可区分质量层次、且与一个独立 prompt 体系高度一致"，不能等同于人工评分信度。
2. **样本分布强双峰**：按档位生成使 24 份被判 0 分、11 份 4 分（两端合计 70%），0 分档的"平凡一致"会推高 Kappa 与相关系数；真实学习者作答更多落在 1~3 的模糊区间，该区间样本仅 15 份。
3. **样本为 LLM 生成**：非真实学员手笔，语言风格与典型错误模式可能与真实作答有差异。
4. **规模有限**：50 份样本、48 道 open 题（2 道重复），单次实验的置信区间较宽。

## 7. 改进方向

1. 小规模人工盲评（20~50 份，教师/助教按标注规程打分），报告 AI 标注代理与人类的对齐度。
2. 引入异厂商模型作第二标注代理，检验同源偏差。
3. 从真实测评中采集作答补充采样，重点覆盖 1~3 分模糊带。
4. 针对"良好/优秀"锚点差异微调 judge prompt，并建立滚动校准机制（每次扩批重跑本脚本）。
