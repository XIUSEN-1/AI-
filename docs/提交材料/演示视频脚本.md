## 拍摄注意事项

1. **真实数据**：全部镜头使用真实系统与真实 DeepSeek Key（判题、SSE、实操窗口均为真实调用），不摆拍假数据；演示前先自跑一轮确认 Key 有效。
2. **网络兜底**：录制约 35 分钟内含多次 LLM 调用，提前确认网络稳定；若判题超时，镜头 7 可剪辑衔接（进度条画面与跳转报告分两段录）。
3. **镜号 4/5 的文字特写**：θ 轨迹与出题理由是"自适应机制有效性"（权重 25%）的直观证据，务必给足特写时长；评分理由特写对应"自动评分准确性"（权重 20%）。
4. **速度**：客观题作答可适当剪辑加速，但对话流式输出与判题进度保持原速——这两处最能体现真实感。
