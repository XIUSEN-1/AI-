# AI 能力罗盘 · 未来发展文档

> 对应赛题 A01 任务要求："未来发展文档（与'AI 智能·教学辅具'数据打通、学习路径推荐、市场推广）"。以下规划区分**已有基础**（仓库真实实现）与**演进方向**（设计中的下一步），不将规划表述为已实现。

## 1. 与"AI 智能·教学辅具"赛题的数据打通

本赛题与"AI 智能·教学辅具"命题同源互补：罗盘回答"学生 AI 能力处于什么水平"，教学辅具回答"如何教学"。打通方案分三步：

1. **能力画像数据接口化**：罗盘的报告数据（六维 θ、L1~L5 等级、逐题判分理由、错题考点标签）已结构化存储于 `reports` / `session_answers` 表；规划新增只读数据出口（按班级/学员授权导出 JSON/CNN 数据集格式），供教学辅具侧读取。
2. **画像驱动教学资源推送**：辅具侧的课程/实验资源按六维考点打标，罗盘的"维度短板 + 薄弱考点标签"（教师看板已有 `weakness_top3` 聚合）直接作为辅具推送依据——学生测评完成即获得辅具中的对应课程包，教师获得班级备课重点。
3. **教学效果回流闭环**：辅具教学后的再测评数据回流罗盘，形成"测评→教学→再测评"的成长曲线（报告页趋势折线已支持多次记录展示），量化教学成效。

## 2. 学习路径推荐深化

已有基础：分级建议库 `seeds/advice_matrix.json`（6 维 × L1~L5 共 30 格，含真实资源与练习任务）+ LLM 个性化组装 + 模板回退。

| 方向 | 内容 |
| --- | --- |
| 对接真实课程库 | 建议资源从静态矩阵升级为可配置课程库（校方维护课程/实验/慕课元数据，按维度×等级×考点三键匹配），推荐从"建议"升级为"可点击直达的学习路径" |
| 题库持续扩充 | 当前 1000 题按"批次扩编+查重+校准"流水线编制；后续按同一方法论横向铺考点、纵向加密难度带（重点补 1~3 分模糊带），并引入题目参数校准流程 |
| IRT 升级 | 引擎从 Elo 期望式更新（`app/engine/adaptive.py`）演进到项目反应理论（2PL/IRT）：题目具备区分度/难度参数后，θ 估计标准误更小、测评题量可进一步缩短；FastAPI + 纯函数架构预留了心理测量库的接入位置 |

## 3. 校企衔接

- **岗位 AI 能力画像**：以六维模型为骨架，叠加岗位权重（如数据分析岗重 D3/D4、内容运营岗重 D2/D6），生成"岗位雷达模板"；学员报告可与目标岗位画像做差集比对，输出差距清单。
- **证书与互认**：L3+ 等级认定结合防作弊机制（实操任务过程留痕、判分复核队列）具备可核验性；规划与院校学分/企业培训体系对接，等级报告作为"AI 素养学分"或企业内训摸底凭证。
- **企业真题池**：开放企业按 rubric 规范（0~4 锚定 + 评分要点）贡献实操任务题，经管理端审核上架，让测评场景贴近真实工作。

## 4. 市场推广路径

```mermaid
flowchart LR
    A[省赛验证<br/>公网演示环境+评委实测] --> B[本校试点<br/>1~2 个班级教学闭环]
    B --> C[校级 SaaS<br/>教务对接·教师培训·报告导出]
    C --> D[区域复制<br/>产教融合站点·多租户部署]
```

1. **省赛验证**：单容器部署（`Dockerfile`/秒悟 Meoo→阿里云 FC）公网可访问，评委托管成本低——这是产品化部署形态的第一次真实演练。
2. **本校试点**：以《软件工程》《人工智能导论》等课程为切入点，课前摸底 + 课后复测，用成长曲线数据说服教务。
3. **校级 SaaS**：多班级/多教师规模化（当前 SQLite 单文件可平移 PostgreSQL；`classes/roles` 模型已按多班级设计），按校交付部署包与运维文档。
4. **产教融合复制**：以"数字马力"产教融合网络为渠道，向合作院校复制"测评 + 教学辅具"组合方案，形成区域级 AI 素养测评基线数据。
